# 🐸 甜呱工作台

> 一个星露谷风格的少女小清新工作台，把生活记账、待办、日程、纪念日、减脂记录、日记、口语练习等都装进一个本地存储的 HTML 文件。

## 怎么用

### 1. 打开应用
- **手机浏览器**：把 `index.html` 发给自己，在微信/QQ/邮件里点开，会自动在浏览器中打开
- **电脑浏览器**：直接双击 `index.html` 或拖入 Chrome/Safari 即可

### 2. 添加到手机主屏幕（像 App 一样打开）
- **iPhone (Safari)**：打开后点底部"分享"按钮 → "添加到主屏幕" → 起个名字"甜呱"
- **Android (Chrome)**：打开后点右上角三个点 → "添加到主屏幕"

添加后桌面上会出现 🐸 图标，点击直接全屏打开，无浏览器地址栏，体验跟 App 一样。

### 3. 配置 AI 视觉识别（可选）
打开「设置」→ 「🤖 AI 视觉识别配置」，填入：
- **API 地址**：默认 `https://api.openai.com/v1/chat/completions`（智谱、通义千问、OpenAI 都兼容这个格式）
- **API Key**：你的服务商密钥（仅保存在你本地浏览器）
- **模型名**：如 `gpt-4o-mini`、`glm-4v`、`qwen-vl-plus` 等多模态模型

填好后，「减脂记录」里上传食物照片可自动算热量，上传运动照片可自动识别运动类型。

### 4. 设置日记 PIN 码
首次进入「日记本」会要求设置 4 位 PIN 码，请妥善记住。
- 本设备本会话内免密查看（关掉浏览器后需重新输入）
- 换设备 / 换浏览器数据不会带过来，需重新验证或重置

## 包含的 9 大模块

| 模块 | 功能 |
|------|------|
| 📝 待办清单 | 今日待办 + 近期待办（7天内），按优先级 |
| 💰 收支记账 | **本年累计收入/支出/结余** 仪表盘，按月分组 |
| 🏃 减脂记录 | 运动 / 体重体脂 / 饮食三合一；**AI 识别照片** 自动填表 |
| 📅 日程月历 | 自绘月历，可切换月份，**日程起止时间** 选择，有日程的日期有彩色圆点 |
| 🌸 纪念日 & 生日 | **支持公历/农历** 生日，自动换算当年公历日期，显示倒计时 |
| 📖 日记本 | PIN 锁保护，**Web Speech 语音输入**，心情+天气 emoji |
| 🌺 经期记录 | 月历标记，自动计算周期+预测下次经期，多症状多选 |
| 📚 阅读口语 | 阅读分阶段计划（书单/进度），口语练习（多邻国连续打卡天数） |
| 🎧 播客小宇宙 | 节目记录、评分、金句、小宇宙链接 |

## 数据备份（重要！）
数据存在浏览器的 localStorage 里：
- ✅ 刷新、关闭浏览器数据不丢
- ⚠️ 换设备/换浏览器/清除浏览器数据 → 数据会丢

**强烈建议定期备份**：
打开「设置」→ 「💾 数据备份」→ 「导出全部数据」下载一个 JSON 文件。
换设备时用「导入数据」即可恢复。

## 隐私说明
- 数据 100% 在你本地浏览器，**不上传任何服务器**
- AI 识别时会调用你配置的 API（图片 base64 发送），请使用你信任的服务
- AI Key 仅保存在 localStorage，不在网络传输

## 浏览器兼容性
- ✅ Chrome / Edge / Safari 现代版本（推荐）
- ✅ 微信内置浏览器
- ⚠️ 语音输入：需 Chrome / Edge / Safari（部分安卓浏览器不支持）

## 技术细节
- 单文件 HTML，无依赖，无构建步骤
- 农历转换算法内置（1900-2100 年农历数据）
- 所有数据存于 localStorage（JSON 序列化）
- 折线图（体重趋势）使用 Canvas 自绘
- 月历、统计、模态框全部原生 CSS
